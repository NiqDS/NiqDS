# Стенды: числа из разборов и сравнений

## Проверки к разбору `docs/split_homogeneity_review_ru.md`

Три скрипта, которыми получены числа из разбора. Запускать вне скилла —
им нужны `numpy scipy pandas scikit-learn` (в `requirements.txt` скилла их
нет намеренно: сам скилл работает на стандартной библиотеке).

```bash
pip install numpy scipy pandas scikit-learn
python3 -I docs/analysis/stratification_sim.py   # доля клиентов в rare_strats
python3 -I docs/analysis/power_check.py          # p-value против размера пилота
python3 -I docs/analysis/homogeneity_checks.py   # 18 тестов + ререндомизация
```

`stratification_sim.py` воспроизводит код из тетрадки дословно по поведению,
на синтетической популяции ММБ. Чтобы проверить на своих данных, замените
`population()` на чтение реального `features` — остальное менять не нужно.

## Сравнение версий: `ab_bench.py`

Прямой прогон нашего сплиттера против версии команды
(`metric_calc_skill/skill/ab_test.py`). Разбор результатов —
`docs/ab_split_benchmark_ru.md`.

```bash
AB_BENCH_THEIRS=/path/to/metric_calc_skill python3 -I docs/analysis/ab_bench.py
```

Их пакет в репозиторий не входит: распакуйте архив и укажите путь (по
умолчанию ищется рядом с папкой скилла). Дополнительных пакетов стенду не
нужно — обе версии на стандартной библиотеке. Качество судится **их**
метрикой (`balance_check`, перекос в сигмах), чтобы сравнение не было
подогнано под наш критерий.

Чтобы добавить третью версию, допишите свой `run_*()` по образцу
`run_theirs()` / `run_ours()` — остальной стенд менять не нужно.

## Короткие списки: `small_list_bench.py`

Матчинг в пары против ререндомизации на списках до 200 клиентов: стартовый
перекос, мощность трёх тестов (Уэлч, парный t, знаковый) и стоимость.
Разбор — `docs/small_lists_ru.md`.

```bash
python3 -I docs/analysis/small_list_bench.py     # около двух минут
```

Зависимостей нет. Строка «нет» в таблице анализа — контроль ложных
срабатываний: если там сильно больше 5%, тест врёт и числам мощности
верить нельзя.
