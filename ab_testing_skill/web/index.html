АБ-тест: параметры пилота

Заполните форму и получите request.json + список ИНН для передачи AB-testing skill. Всё выполняется локально в браузере — файлы никуда не отправляются, пока вы сами их не передадите агенту.

1. Пилот

Пересчёт фин. эффектов выполняется ежемесячно — единственный доступный режим.

2. Контакты

Исходный список ИНН и параметры пилота (request.json) уходят только этому аналитику — до валидации и разбиения на группы.

3. Список ИНН (ЦГ-кандидаты)

Это только предпросмотр в браузере (количество строк, явно некорректные значения). Полная валидация (контрольная сумма ИНН, проверка на дубли по «задействованным ИННкам») выполняется агентом на шаге 1-2.

4. Атрибуты для разбиения на КГ и ЦГ

Отметьте галочками нужные метрики — можно выбрать несколько.

5. Статьи расчета фин. эффекта пилота

Отметьте галочками нужные метрики — можно выбрать несколько.

Эти же метрики используются агентом при периодическом пересчёте (шаг 6) для дэшборда в Навигаторе.

6. Как делить список: опрос о пилоте

Пять вопросов о том, как устроен ваш пилот. По ответам агент сам предложит метод разделения — одномоментный или каскадный, с ребейзом. Ничего знать про статистику не нужно: отвечайте про запуск, а не про расчёты.
